# 0.5–300 Hz Morlet 频率密度消融

对比 40 与 100 个对数频率中心，保留 0.5–300 Hz 带通、7 cycles 功率、每十点取一点到 100 Hz 的方案。两组共享 100 槽 RecurFlex 输入、6,980,230 参数以及初始化；40 点组未用的 60 槽置零。所有非输入层参数保留原主干 seed 42 的初始值。

## 参数与控制

频率为 `logspace(log10(0.5),log10(300),40/100)`。40 点中有 13 点位于 40–300 Hz，100 点中有 32 点。低频小波时间支持及功率表示保持不变。

固定每被试 16 个原训练选定电极、训练目标 MinMax、窗口采样序列、seed 42、AdamW lr 8.42e-5、weight_decay 1e-4、dropout 0.1、batch 64。每轮 8192 个 512 点窗口，推理 2048 点，输出整窗，同时间标签配对。损失为 0.5 MSE + 0.5 时间轴 cosine distance。

40 点原始功率缓存复用上一轮宽频实验，并校验哈希。100 点特征重新提取；四个共有频率中心核对一致。每个表示分别拟合训练 RobustScaler，quantile_range=(0.1,0.9) 为百分位数 0.1 与 0.9，unit_variance=True，输入增益 1。

主要比较本次同容量 40 与 100 点的差值。前一轮 40 点宽频结果来自 43 槽模型，输入层尺寸与初始值不同，作为历史参考。正式评分使用每被试完整 200000 个原始 1000 Hz 测试点，四指 r 排除无名指，三个被试等权平均；五指指标为辅助。

服务器独立目录为 `/root/autodl-tmp/bci_paper_morlet100_20261008`。依次用 `remote.py inspect/setup/launch/monitor/fetch` 操作；密码只在不回显提示中输入。旧实验不被覆盖。冻结六份预测并下载后，用主实验 Python 环境运行 `score_and_report.py`；再运行 `make_notebook.py` 与 `execute_results.py`，保存表格和图片到 notebook。
