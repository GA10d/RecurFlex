# Feature-ablation source snapshots

This directory preserves the feature-selection source and selected score summaries underlying the manuscript's frequency-feature ablations. It contains the controlled high/low-frequency experiments and subsequent frequency-grid and signed-band comparisons.

These scripts retain the original experiment layout and historical paths. Some orchestration scripts and historical README commands reference server-transfer utilities, generated inputs, or checkpoints that are not included in this public package. They are experiment source snapshots, not an additional standalone quick-start pipeline. Server connection utilities and credentials are excluded.

Use the self-contained [BCI main experiment](../../Main%20Experiment) for the documented reproduction commands. Refer to [the manuscript table](../../../overleaf/tables/feature_ablation.tex) for the reported ablation scores and matched settings.
