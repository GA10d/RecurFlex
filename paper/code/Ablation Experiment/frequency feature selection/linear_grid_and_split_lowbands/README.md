# 等间隔 Morlet 与四路有符号低频消融

两组请求分别为：仅 0.5–300 Hz 的 40 个等间隔 Morlet 功率中心；原 40–300 Hz 的 40 个对数 Morlet 中心，加 0.5–4、4–8、8–13、13–30 Hz 四路有符号低频。

另重训一个 44 槽的原三路低频对照。2026-10-08，三组三个被试、九次全量训练及完整测试均已完成，权重与预测冻结、下载并核对哈希。原模型和已有实验保留。

## 特征与模型

第一组频率为 `linspace(0.5,300,40)`，步长约 7.67949 Hz，34 个中心在 40–300 Hz。保持 0.5–300 Hz 带通、60 Hz 谐波陷波、7 cycles、zero_mean=False、功率输出与每十点取一点到 100 Hz。模型输入为 43 槽，最后三槽置零，参数 6,805,126；初始化与上一轮仅 Morlet、宽频 40 点对数 Morlet 完全一致。

第二组直接复用原高频功率缓存。四路低频从逐通道标准化、全部电极中位数参考后的原信号提取，在高频带通前用四阶 Butterworth 与 sosfiltfilt 滤波，保留正负值并每十点取一点。Delta、Beta 与原缓存核对一致；Theta 和 Alpha 替代原 4–13 Hz 合并带。各路训练 RobustScaler 缩放后 ×200，与原低频分支相同。

两种混合输入共用 44 槽、6,808,198 参数和相同初始化。规范槽位为 40=Delta、41=Theta 或原4–13、42=Alpha或零、43=Beta。原三路对照将槽42置零。输入层既有权重按此映射复制，所有其他张量保留原 seed42 初值；只新增 Alpha 槽的随机初值。初始三路对照的输出与原模型核对一致。

## 固定训练与测试

复用原训练选定的 16 个电极和目标 MinMax，seed42，512 点训练、2048 点全输出推理，同时间标签配对。S1/S2/S3 分别训练 112/69/104 轮，每轮 8192 个窗口，batch64。AdamW lr8.42e-5、weight_decay1e-4、dropout0.1，损失0.5 MSE+0.5时间轴cosine distance。各模型采样序列与上一轮核对相同。

使用最终普通权重。九份权重与测试预测冻结后，本地读取每被试完整 200000 点原始测试标签评分，四指排除无名指，三个被试等权平均；五指辅助。
